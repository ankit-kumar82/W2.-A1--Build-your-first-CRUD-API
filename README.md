# FlyRank Backend Internship Week 2 Assignment - Build Your First CRUD API

A clean, robust, and fully documented RESTful CRUD API built with Python 3.10+ and FastAPI. Data is strictly stored in-memory, validated via Pydantic models, and auto-documented with OpenAPI / Swagger UI.

---

## Features

- **FastAPI Framework**: High performance, modern API backend.
- **In-Memory Storage**: State preserved purely in memory without external database overhead.
- **Pydantic Validation**: Robust request payload validation and custom error formatting.
- **Full CRUD Operations**:
  - `GET /tasks` - List all tasks with status filtering (`?done=true`) and search (`?search=query`).
  - `GET /tasks/{id}` - Fetch single task or return `404 Task not found`.
  - `POST /tasks` - Add new task (auto ID assignment, `done=false`, title validation).
  - `PUT /tasks/{id}` - Update title and/or done status.
  - `DELETE /tasks/{id}` - Delete task (returns `204 No Content`).
- **Bonus Features**:
  - `GET /stats` - Summary of total, open, and completed tasks.
  - `POST /reset` - Restore original seed dataset.
- **Interactive OpenAPI Docs**: Complete Swagger UI with summaries, descriptions, status codes, and schemas for every endpoint.

## Installation & Setup

1. **Clone or navigate to the repository:**
   ```bash
   cd todo-api
   ```

2. **Create a virtual environment:**
   ```bash
   python -m venv venv
   ```

3. **Activate the virtual environment:**
   - **Windows (PowerShell):**
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - **Windows (CMD):**
     ```cmd
     .\venv\Scripts\activate.bat
     ```
   - **macOS / Linux:**
     ```bash
     source venv/bin/activate
     ```

4. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Run Command

Start the server locally using Uvicorn:

```bash
uvicorn app.main:app --reload
```

The application server will start at: `http://127.0.0.1:8000`

## API Endpoint Table

| Method | Endpoint | Status Code | Description |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | `200 OK` | API details and metadata |
| `GET` | `/health` | `200 OK` | Server health status check |
| `GET` | `/stats` | `200 OK` | Statistical summary of tasks |
| `POST` | `/reset` | `200 OK` | Reset dataset to initial state |
| `GET` | `/tasks` | `200 OK` | Get all tasks (supports `done` & `search` query params) |
| `GET` | `/tasks/{id}` | `200 OK` / `404` | Get task by ID |
| `POST` | `/tasks` | `201 Created` / `400` | Create new task |
| `PUT` | `/tasks/{id}` | `200 OK` / `400` / `404` | Update task title/status |
| `DELETE` | `/tasks/{id}` | `204 No Content` / `404` | Delete task by ID |

## Sample `curl` Commands

### 1. Root Metadata
```bash
curl -X GET "http://127.0.0.1:8000/"
```

### 2. Health Check
```bash
curl -X GET "http://127.0.0.1:8000/health"
```

### 3. Get All Tasks
```bash
curl -X GET "http://127.0.0.1:8000/tasks"
```

### 4. Filter Tasks by Status (`done=true`)
```bash
curl -X GET "http://127.0.0.1:8000/tasks?done=true"
```

### 5. Search Tasks by Keyword (`search=fastapi`)
```bash
curl -X GET "http://127.0.0.1:8000/tasks?search=fastapi"
```

### 6. Get Task by ID
```bash
curl -X GET "http://127.0.0.1:8000/tasks/1"
```

### 7. Create New Task
```bash
curl -X POST "http://127.0.0.1:8000/tasks" \
     -H "Content-Type: application/json" \
     -d '{"title": "Buy milk"}'
```

### 8. Update Task
```bash
curl -X PUT "http://127.0.0.1:8000/tasks/1" \
     -H "Content-Type: application/json" \
     -d '{"title": "Learn FastAPI Advanced", "done": true}'
```

### 9. Delete Task
```bash
curl -X DELETE "http://127.0.0.1:8000/tasks/1"
```

### 10. Get Task Statistics
```bash
curl -X GET "http://127.0.0.1:8000/stats"
```

### 11. Reset Tasks to Initial State
```bash
curl -X POST "http://127.0.0.1:8000/reset"
```
